สัญญาณอนาล็อก (Analog) และ PWM

เรียนรู้การอ่านค่าความต่างศักย์แบบต่อเนื่อง และการจำลองสัญญาณอนาล็อกเพื่อหรี่ไฟหรือคุมความเร็วมอเตอร์

1. ทฤษฎีเบื้องต้น (Introduction)

Analog to Digital Converter (ADC)

ไมโครคอนโทรลเลอร์ไม่เข้าใจแรงดันไฟฟ้าแบบต่อเนื่อง (Analog) เช่น 0 ถึง 5V จึงต้องแปลงเป็นตัวเลขดิจิทัล (Digital) ผ่านระบบ ADC

  • Arduino Uno: ความละเอียด 10-bit แปลงแรงดัน 0-5V เป็นตัวเลข 0 ถึง 1023
  • ขาที่รองรับ: ขา A0 ถึง A5
  • คำสั่ง: analogRead(pin);

Pulse Width Modulation (PWM)

การจำลองสัญญาณอนาล็อกเพื่อส่งออกไปยังอุปกรณ์ภายนอก โดยการเปิด/ปิดสัญญาณดิจิทัลด้วยความเร็วสูงสลับกัน (Duty Cycle)

  • Arduino Uno: ความละเอียด 8-bit ส่งค่า 0 ถึง 255 (0 = 0V, 255 = 5V)
  • ขาที่รองรับ: ขาที่มีเครื่องหมาย ~ (เช่น 3, 5, 6, 9, 10, 11)
  • คำสั่ง: analogWrite(pin, value);

📐 การคำนวณแรงดันไฟฟ้าเฉลี่ย (Average Voltage) ของ PWM

PWM ไม่ได้ปล่อยแรงดันต่ำลงจริงๆ แต่ปล่อย 5V สลับ 0V ด้วยความถี่สูง (~490Hz) ทำให้อุปกรณ์โหลดแบบเหนี่ยวนำหรือความต้านทาน เช่น LED หรือ มอเตอร์ มองเห็นเป็นแรงดันเฉลี่ย:

V_avg = V_peak x ( Duty Cycle % / 100 )
Duty Cycle (%) = ( analogWrite_value / 255 ) x 100
ค่า analogWrite() Duty Cycle (%) แรงดันเฉลี่ย V_avg (5V Uno) แรงดันเฉลี่ย V_avg (3.3V ESP32) ผลลัพธ์ที่ LED
0 0% (LOW ตลอด) 0.00 V 0.00 V ดับสนิท
64 25% 1.25 V 0.82 V สว่าง 25%
128 50% 2.50 V 1.65 V สว่างครึ่งหนึ่ง
191 75% 3.75 V 2.47 V สว่าง 75%
255 100% (HIGH ตลอด) 5.00 V 3.30 V สว่างเต็มที่ 100%

⚡ PWM vs True DAC (สัญญาณแอนะล็อกแท้)

  • Arduino Uno (PWM): ไม่มี DAC แท้ สัญญาณยังคงเป็น Digital Pulse เหมาะกับหรี่ไฟ LED, คุมความเร็วมอเตอร์ แต่ไม่เหมาะกับงานเครื่องเสียง Hi-Fi
  • ESP32 (True DAC): มี DAC 8-bit แท้ 2 ช่อง (GPIO 25, GPIO 26) จ่ายแรงดันแอนะล็อกแท้เรียบเนียนด้วยคำสั่ง dacWrite(25, 128);

🚗 การประยุกต์ใช้ PWM ขับมอเตอร์ DC (H-Bridge Driver)

ห้ามต่อมอเตอร์เข้าขา Arduino ตรงๆ เด็ดขาด! ต้องใช้บอร์ดขับ เช่น L298N หรือ MOSFET Driver:

  • จ่ายสัญญาณ PWM เข้าขา ENA / ENB เพื่อควบคุมความเร็วรอบ
  • จ่ายสัญญาณ HIGH/LOW เข้าขา IN1 / IN2 เพื่อกลับทิศทางการหมุน

2. วงจรจำลอง (Interactive Simulator)

ทดลองเลื่อนแถบสไลด์ (ตัวต้านทานปรับค่าได้) เพื่อดูการเปลี่ยนแปลงของค่า ADC และความสว่างของ LED ผ่าน PWM

ADC: 0
PWM: 0
analog_pwm.ino 
const int potPin = A0;  // ขาต่อตัวต้านทานปรับค่าได้
const int ledPin = 9;   // ขาต่อ LED (ต้องรองรับ PWM ~)

int analogValue = 0;
int pwmValue = 0;

void setup() {
  Serial.begin(9600);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // 1. อ่านค่า ADC (0 - 1023)
  analogValue = analogRead(potPin);
  
  // 2. แปลงช่วงค่าจาก 0-1023 ให้เป็น 0-255
  pwmValue = map(analogValue, 0, 1023, 0, 255);
  
  // 3. สั่งงาน LED ด้วย PWM
  analogWrite(ledPin, pwmValue);
  
  // พิมพ์ค่าออก Serial Monitor
  Serial.print("ADC: ");
  Serial.print(analogValue);
  Serial.print(" | PWM: ");
  Serial.println(pwmValue);
  
  delay(10);
}
