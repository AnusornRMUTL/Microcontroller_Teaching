1. ทำความรู้จัก I/O Port (Input / Output)

ไมโครคอนโทรลเลอร์อย่าง Arduino UNO สื่อสารกับโลกภายนอกผ่านพอร์ตอินพุตและเอาต์พุต (I/O Ports) ซึ่งเปรียบเสมือนแขนขาที่ใช้รับความรู้สึกและสั่งการ

📥 Input (อินพุต)

รับสัญญาณจากภายนอก เช่น การกดปุ่ม (Push Button), เซ็นเซอร์แสง, เซ็นเซอร์อุณหภูมิ

pinMode(pin, INPUT);

📤 Output (เอาต์พุต)

ส่งสัญญาณออกไปควบคุมอุปกรณ์ภายนอก เช่น เปิด/ปิดหลอดไฟ (LED), หมุนมอเตอร์, ส่งเสียงเตือน

pinMode(pin, OUTPUT);

คำสั่งพื้นฐานที่ใช้บ่อย (Digital I/O)

  • pinMode(pin, INPUT / OUTPUT / INPUT_PULLUP) : กำหนดทิศทางของขาพอร์ต
  • digitalWrite(pin, HIGH / LOW) : สั่งจ่ายไฟ (HIGH = 5V) หรือหยุดจ่ายไฟ (LOW = 0V)
  • digitalRead(pin) : อ่านสถานะของขาพอร์ต (HIGH หรือ LOW)

⚠️ ปัญหาขาอินพุตลอย (Floating Pin) และตัวต้านทาน Pull-up / Pull-down

ขาอินพุตของไมโครคอนโทรลเลอร์มีความต้านทานภายในสูงมาก หากไม่ต่อตัวต้านทานกำกับไว้ ขาจะทำหน้าที่เสมือนเสาอากาศรับสัญญาณรบกวนในอากาศ ทำให้อ่านค่าได้ไม่แน่นอน (0 สลับ 1 มั่ว):

1. Pull-up ภายนอก (Active LOW)

ต่อตัวต้านทาน 10kΩ ดึงขาไปที่ 5V (VCC) และต่อสวิตช์ลง GND

  • ไม่กดปุ่ม: อ่านได้ HIGH (5V)
  • กดปุ่ม: อ่านได้ LOW (0V)

2. ภายในชิป (INPUT_PULLUP) ✨ นิยมที่สุด

Arduino มีตัวต้านทาน Pull-up ภายในขนาด 20kΩ-50kΩ ให้เรียกใช้ได้เลย

pinMode(2, INPUT_PULLUP);

เพียงต่อสวิตช์ระหว่างขา 2 กับ GND ไม่ต้องใช้ตัวต้านทานภายนอก!

3. Pull-down (Active HIGH)

ต่อตัวต้านทาน 10kΩ ดึงขาไปที่ GND และต่อสวิตช์ไปที่ 5V (VCC)

  • ไม่กดปุ่ม: อ่านได้ LOW (0V)
  • กดปุ่ม: อ่านได้ HIGH (5V)

📐 การคำนวณตัวต้านทาน LED & วงจรขับโหลดกำลัง (Industrial Driving)

สูตรคำนวณตัวต้านทาน LED (Current Limiting)

ห้ามต่อ LED ตรงกับขาพอร์ตโดยไม่มีตัวต้านทาน เพราะจะดึงกระแสเกินจนชิปพัง!

R = (V_CC - V_LED) / I_LED
R = (5V - 2.0V) / 0.015A = 200 Ω

👉 เลือกใช้ค่ามาตรฐาน: 220 Ω หรือ 330 Ω (กระแสปลอดภัย ~10-15 mA)

การขับ Relay / โซลินอยด์ในอุตสาหกรรม

ขาไมโครคอนโทรลเลอร์จ่ายไฟได้สูงสุดเพียง 20-40 mA ไม่สามารถขับรีเลย์ตรงๆ ได้ ต้องใช้:

  • Transistor / MOSFET: เป็นสวิตช์ขยายกระแส
  • Optocoupler: แยกกราวด์สัญญาณและกราวด์กำลัง (Noise Isolation)
  • Flyback Diode (1N4007): ต่อขนานย้อนทางกับขดลวดรีเลย์เพื่อป้องกัน Back-EMF กระชากกลับทำลายวงจร

2. วงจรจำลอง: ควบคุม LED ด้วยปุ่มกด

ทดลองกดปุ่มบนวงจรจำลองด้านล่าง เพื่อดูการทำงานของสัญญาณไฟ (กระแสไฟฟ้า) และโค้ด Arduino ที่ทำงานสอดคล้องกัน

button_led.ino 

// กำหนดขาพอร์ต
const int buttonPin = 2;
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
  pinMode(buttonPin, INPUT);
}

void loop() {
  // อ่านสถานะปุ่ม
  int buttonState = digitalRead(buttonPin);

  if (buttonState == HIGH) {
    // ถ้าปุ่มถูกกด (HIGH) ให้เปิด LED
    digitalWrite(ledPin, HIGH);
  } else {
    // ถ้าไม่กด (LOW) ให้ปิด LED
    digitalWrite(ledPin, LOW);
  }
}
