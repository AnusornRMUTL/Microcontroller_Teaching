1. การรับ-ส่งข้อมูล (Data Transfer)

ไมโครคอนโทรลเลอร์ประมวลผลข้อมูลในรูปแบบของ บิต (Bit) ซึ่งก็คือสถานะทางไฟฟ้า 0 (LOW) และ 1 (HIGH) เมื่อต้องการส่งข้อมูลไปให้อุปกรณ์อื่น เช่น ส่งตัวอักษร 'A' (มีรหัสฐานสองคือ 01000001 ขนาด 8-bit) จะมีวิธีการส่งหลักๆ 2 แบบ คือ

ขนาน (Parallel) 8-bit

ส่งข้อมูลทั้ง 8 บิตไปพร้อมๆ กันในครั้งเดียว โดยต้องใช้สายไฟอย่างน้อย 8 เส้น (ไม่รวมสาย GND)

  • ✅ ข้อดี: ส่งข้อมูลได้เร็วมาก
  • ❌ ข้อเสีย: สิ้นเปลืองสายไฟ ไม่เหมาะกับระยะทางไกล เพราะสัญญาณอาจกวนกัน

อนุกรม (Serial)

ส่งข้อมูลทีละบิต เรียงต่อกันไปตามสายไฟเพียง 1 เส้น (TX ไปยัง RX)

  • ✅ ข้อดี: ประหยัดสายไฟ ส่งระยะไกลได้ดีเยี่ยม
  • ❌ ข้อเสีย: ช้ากว่าแบบขนาน (แต่ในปัจจุบันพัฒนาจนเร็วมากแล้ว)

คำสั่ง Arduino ที่เกี่ยวข้อง (Serial Communication)

  • Serial.begin(speed); : เปิดใช้งานพอร์ตสื่อสาร เช่น 9600 หรือ 115200 bps
  • Serial.available(); : ตรวจสอบจำนวนไบต์ที่รออยู่ใน Receive Buffer (FIFO)
  • Serial.read(); : อ่านข้อมูล 1 ไบต์แรกที่อยู่ใน Buffer ออกมาประมวลผล
  • Serial.print() / println(); : ส่งข้อมูลออกไปยังขา TX

🔄 ทิศทางการส่งข้อมูล (Communication Modes)

1. ซิมเพล็กซ์ (Simplex)

ส่งข้อมูลได้ ทิศทางเดียวตลอดเวลา ฝั่งรับไม่สามารถตอบกลับได้

ตัวอย่าง: สัญญาณวิทยุกระจายเสียง, รีโมตทีวี, เซนเซอร์ส่งอย่างเดียว

2. ฮาล์ฟดูเพล็กซ์ (Half-Duplex)

ส่งได้ 2 ทิศทาง แต่ต้องสลับกัน ไม่สามารถส่งพร้อมกันได้

ตัวอย่าง: วิทยุสื่อสาร (Walkie-Talkie), I2C, RS485 ระบบ 2 สาย

3. ฟูลดูเพล็กซ์ (Full-Duplex)

รับและส่งข้อมูลได้ พร้อมกันทั้ง 2 ทิศทางในเวลาเดียวกัน

ตัวอย่าง: โทรศัพท์, UART (Tx/Rx), RS232, SPI

⏱️ ซิงโครนัส vs อะซิงโครนัส

  • Synchronous (ซิงโครนัส): ใช้สายสัญญาณนาฬิกา (Clock) กำกับจังหวะ (เช่น I2C, SPI) ความเร็วสูง ไม่ต้องระบุ Baud rate ล่วงหน้า
  • Asynchronous (อะซิงโครนัส): ไม่มีสาย Clock (เช่น UART, RS232, RS485) ต้องตั้งความเร็ว Baud rate ให้ตรงกันล่วงหน้า และใช้ Start/Stop bit กำกับเฟรม

📥 หน่วยความจำพักข้อมูล (Serial FIFO Buffer)

Arduino มีบัฟเฟอร์ขนาด 64 Bytes คอยรับข้อมูลเข้าอัตโนมัติ การเขียนโค้ดที่ถูกต้องระดับ ปวส. ต้องเช็คว่ามีข้อมูลก่อนอ่านเสมอ:

while (Serial.available() > 0) {
  char inChar = (char)Serial.read();
}

2. วงจรจำลอง: เปรียบเทียบ Serial และ Parallel

จำลองการส่งข้อมูลตัวอักษร 'A' (01000001) จาก Arduino เครื่องส่ง ไปยังเครื่องรับ เลือกระบบที่ต้องการทดสอบแล้วกดปุ่ม "ส่งข้อมูล"

ข้อมูลที่รับได้: ___
sender_serial.ino 

// โหมด: Serial Communication
void setup() {
  // เปิดพอร์ตซีเรียล ความเร็ว 9600 bps
  Serial.begin(9600);
}

void loop() {
  // รอรับคำสั่งให้ส่งข้อมูล
  Serial.print("A"); // ส่ง 'A' (01000001)
  
  delay(1000);
}
