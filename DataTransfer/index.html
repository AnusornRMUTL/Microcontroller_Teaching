1. การรับ-ส่งข้อมูล (Data Transfer)

ไมโครคอนโทรลเลอร์ประมวลผลข้อมูลในรูปแบบของ บิต (Bit) ซึ่งก็คือสถานะทางไฟฟ้า 0 (LOW) และ 1 (HIGH) เมื่อต้องการส่งข้อมูลไปให้อุปกรณ์อื่น เช่น ส่งตัวอักษร 'A' (มีรหัสฐานสองคือ 01000001 ขนาด 8-bit) จะมีวิธีการส่งหลักๆ 2 แบบ คือ

ขนาน (Parallel) 8-bit

ส่งข้อมูลทั้ง 8 บิตไปพร้อมๆ กันในครั้งเดียว โดยต้องใช้สายไฟอย่างน้อย 8 เส้น (ไม่รวมสาย GND)

  • ✅ ข้อดี: ส่งข้อมูลได้เร็วมาก
  • ❌ ข้อเสีย: สิ้นเปลืองสายไฟ ไม่เหมาะกับระยะทางไกล เพราะสัญญาณอาจกวนกัน

อนุกรม (Serial)

ส่งข้อมูลทีละบิต เรียงต่อกันไปตามสายไฟเพียง 1 เส้น (TX ไปยัง RX)

  • ✅ ข้อดี: ประหยัดสายไฟ ส่งระยะไกลได้ดีเยี่ยม
  • ❌ ข้อเสีย: ช้ากว่าแบบขนาน (แต่ในปัจจุบันพัฒนาจนเร็วมากแล้ว)

คำสั่ง Arduino ที่เกี่ยวข้อง (Serial)

  • Serial.begin(9600); : เปิดใช้งานการสื่อสารอนุกรมที่ความเร็ว 9600 บิตต่อวินาที (Baud rate)
  • Serial.print("A"); : ส่งข้อมูลออกไปทางขา TX (Pin 1)

2. วงจรจำลอง: เปรียบเทียบ Serial และ Parallel

จำลองการส่งข้อมูลตัวอักษร 'A' (01000001) จาก Arduino เครื่องส่ง ไปยังเครื่องรับ เลือกระบบที่ต้องการทดสอบแล้วกดปุ่ม "ส่งข้อมูล"

ข้อมูลที่รับได้: ___
sender_serial.ino 

// โหมด: Serial Communication
void setup() {
  // เปิดพอร์ตซีเรียล ความเร็ว 9600 bps
  Serial.begin(9600);
}

void loop() {
  // รอรับคำสั่งให้ส่งข้อมูล
  Serial.print("A"); // ส่ง 'A' (01000001)
  
  delay(1000);
}
