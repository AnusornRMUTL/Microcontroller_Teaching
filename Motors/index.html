การควบคุมมอเตอร์ (Motor Control)

ศึกษาทฤษฎีการขับโหลดกำลังสูง, วงจร H-Bridge, ไอซีขับ L298N, ULN2003 และการสร้างพัลส์ควบคุมเซอร์โวมอเตอร์

1. ทฤษฎีและความแตกต่างของมอเตอร์ทั้ง 3 ชนิด

ในงานไมโครคอนโทรลเลอร์และระบบอัตโนมัติ มอเตอร์ไฟฟ้าเป็นอุปกรณ์แปลงพลังงานไฟฟ้าให้กลายเป็นพลังงานกลที่สำคัญที่สุด แต่เนื่องจากมอเตอร์แต่ละประเภทมีจุดเด่นและหลักการควบคุมที่แตกต่างกัน วิศวกรจึงต้องเลือกใช้งานให้เหมาะสมกับลักษณะงาน:

🔴 มอเตอร์ไฟฟ้ากระแสตรง (DC Motor)

เน้น: ความเร็วรอบสูง ต่อเนื่อง ราคาประหยัด

  • หลักการ: ใช้แรงดูด-ผลักของแม่เหล็กไฟฟ้าในทุ่นอาร์เมเจอร์
  • การควบคุม: สลับขั้วไฟฟ้าเพื่อเปลี่ยนทิศทาง (H-Bridge) และปรับแรงดัน/PWM เพื่อควบคุมความเร็ว
  • จุดเด่น: ความเร็วสูง (หลักพันถึงหมื่น RPM), โครงสร้างไม่ซับซ้อน
  • จุดด้อย: ควบคุมมุมองศาที่แน่นอนไม่ได้หากไม่มีเอ็นโค้ดเดอร์
  • งานที่ใช้: ล้อรถของเล่น, พัดลมระบายความร้อน, สว่านไฟฟ้า

🟠 สเต็ปเปอร์มอเตอร์ (Stepper Motor)

เน้น: ความแม่นยำของมุม/ก้าว ล็อคตำแหน่งนิ่ง

  • หลักการ: จ่ายไฟกระตุ้นขดลวดแม่เหล็กทีละเฟสเพื่อดึงโรเตอร์ทีละก้าว (Step)
  • การควบคุม: ส่งพัลส์ตามลำดับ Sequence (Wave, Full, Half Step) ผ่านไอซี ULN2003 หรือไดรเวอร์เฉพาะ
  • จุดเด่น: เคลื่อนที่ตามจำนวนสเต็ปที่สั่งได้เป๊ะ (Open-loop) และมี Holding Torque ล็อคแกน
  • จุดด้อย: ความเร็วรอบต่ำ, กินไฟตลอดเวลาแม้หยุดนิ่ง
  • งานที่ใช้: เครื่องพิมพ์ 3 มิติ (3D Printer), เครื่อง CNC, สแกนเนอร์

🔵 เซอร์โวมอเตอร์ (RC Servo Motor)

เน้น: ควบคุมมุมองศา 0-180° แรงบิดสูง

  • หลักการ: มอเตอร์ DC + เกียร์ทด + วงจรควบคุมและเซนเซอร์โพเทนชิโอมิเตอร์ป้อนกลับ (Closed-loop)
  • การควบคุม: ส่งสัญญาณพัลส์ PWM 50Hz (ความกว้าง 1.0ms - 2.0ms ระบุมุม 0°-180°)
  • จุดเด่น: สั่งมุมได้ทันที แรงบิดสูงเทียบกับขนาด กินกระแสตามภาระโหลด
  • จุดด้อย: มุมหมุนจำกัด (ส่วนใหญ่ 180°), ไม่สามารถหมุนต่อเนื่องแบบ 360° ได้ตามปกติ
  • งานที่ใช้: แขนกลอุตสาหกรรม, ไม้กั้นทาง, ปีกบังคับโดรน/เครื่องบิน

2. มอเตอร์กระแสตรง และโมดูลขับมอเตอร์ L298N (H-Bridge)

📑 ดาวน์โหลด L298N Datasheet (PDF)

มอเตอร์กระแสตรง (DC Motor) เปลี่ยนทิศทางการหมุนตามทิศทางการไหลของกระแสไฟฟ้า เพื่อหลีกเลี่ยงการสลับสายไฟด้วยมือ เราจึงใช้วงจร H-Bridge ซึ่งใช้สวิตช์อิเล็กทรอนิกส์ (ทรานซิสเตอร์) 4 ตัว ทำหน้าที่สลับทิศทางกระแสไฟฟ้า

ตารางการทำงานของ L298N (ช่องขับ A)

ขา ENA (PWM) ขา IN1 ขา IN2 ทิศทางการหมุนของมอเตอร์ สถานะเอาต์พุต (OUT1, OUT2)
HIGH / PWM HIGH (1) LOW (0) หมุนตามเข็มนาฬิกา (CW / เดินหน้า) OUT1 = Vms, OUT2 = GND
HIGH / PWM LOW (0) HIGH (1) หมุนทวนเข็มนาฬิกา (CCW / ถอยหลัง) OUT1 = GND, OUT2 = Vms
HIGH HIGH (1) HIGH (1) หยุดทันทีแบบเบรก (Dynamic Braking) OUT1 = Vms, OUT2 = Vms (ช็อตขั้ว)
LOW (0) X (ค่าใดก็ได้) X (ค่าใดก็ได้) ปล่อยฟรีหยุดหมุน (Coast / Standby) วงจรตัดไฟ ไม่จ่ายกระแส

🔌 ตารางการเชื่อมต่อวงจรระหว่าง ESP32 DevKit V1 และ โมดูล L298N

ขา ESP32 DevKit ขาโมดูล L298N หน้าที่และประเภทสัญญาณ สีสายไฟในภาพ
GPIO 14 (D14) ENA (ถอด Jumper ออก) สัญญาณ PWM ความถี่ 5kHz ปรับความเร็วรอบ (0–255) 🔵 สีฟ้า (Blue)
GPIO 27 (D27) IN1 สัญญาณลอจิกดิจิทัลควบคุมทิศทาง (Logic Direction 1) 🟡 สีเหลือง (Yellow)
GPIO 26 (D26) IN2 สัญญาณลอจิกดิจิทัลควบคุมทิศทาง (Logic Direction 2) 🟢 สีเขียว (Green)
GND GND กราวด์ร่วม (Common GND) จำเป็นต้องต่อถึงกันเพื่อให้ระดับสัญญาณอ้างอิงตรงกัน ⚫ สีดำ (Black)
แหล่งจ่ายไฟภายนอก (+) +12V (VMS) ไฟเลี้ยงมอเตอร์กระแสตรง (แบตเตอรี่ หรือ Adapter 7V - 12V DC) 🔴 สีแดง (Red)
ขั้วมอเตอร์ DC (M1) OUT1, OUT2 ขั้วต่อกระแสไฟฟ้าขับโหลดมอเตอร์ DC สลับขั้วตามลอจิก H-Bridge 🔴 แดง / 🔵 น้ำเงิน

// ======================================================== // ควบคุมความเร็วและทิศทาง DC Motor ด้วย ESP32 และ L298N // ======================================================== // กำหนดขา GPIO ของ ESP32 ให้ตรงกับวงจรในภาพ const int pinENA = 14; // ขา PWM คุมความเร็ว (ต่อกับ ENA) const int pinIN1 = 27; // ขาดิจิทัลคุมทิศทาง (ต่อกับ IN1) const int pinIN2 = 26; // ขาดิจิทัลคุมทิศทาง (ต่อกับ IN2) // ตั้งค่าคุณสมบัติสัญญาณ PWM (LEDC สำหรับ ESP32) const int pwmFreq = 5000; // ความถี่ 5 kHz สำหรับ DC Motor const int pwmChannel = 0; // LEDC Channel 0 const int pwmResolution = 8; // ความละเอียด 8-bit (0 - 255) void setup() { Serial.begin(115200); // 1. กำหนดโหมดขาเอาต์พุตดิจิทัล pinMode(pinIN1, OUTPUT); pinMode(pinIN2, OUTPUT); // 2. กำหนดช่องสัญญาณ PWM ของ ESP32 (Core 2.x) ledcSetup(pwmChannel, pwmFreq, pwmResolution); ledcAttachPin(pinENA, pwmChannel); // หมายเหตุ: ใน ESP32 Core 3.x ขึ้นไป สามารถใช้ ledcAttach(pinENA, 5000, 8) // หรือใช้ analogWrite(pinENA, value) ได้โดยตรง Serial.println("ESP32 + L298N DC Motor Ready!"); } void loop() { // --- ขั้นที่ 1: หมุนตามเข็ม (CW) ความเร็ว 200 (ประมาณ 78%) --- Serial.println("1. หมุนตามเข็มนาฬิกา (CW) - Speed: 200/255"); digitalWrite(pinIN1, HIGH); digitalWrite(pinIN2, LOW); ledcWrite(pwmChannel, 200); delay(3000); // --- ขั้นที่ 2: หยุดแบบเบรกทันที (Brake) 1 วินาที --- Serial.println("2. เบรกหยุดทันที (Brake)"); digitalWrite(pinIN1, HIGH); digitalWrite(pinIN2, HIGH); ledcWrite(pwmChannel, 0); delay(1000); // --- ขั้นที่ 3: หมุนทวนเข็ม (CCW) ความเร็ว 150 (ประมาณ 59%) --- Serial.println("3. หมุนทวนเข็มนาฬิกา (CCW) - Speed: 150/255"); digitalWrite(pinIN1, LOW); digitalWrite(pinIN2, HIGH); ledcWrite(pwmChannel, 150); delay(3000); // --- ขั้นที่ 4: หยุดแบบปล่อยอิสระ (Coast) 1.5 วินาที --- Serial.println("4. ปล่อยอิสระ (Coast)"); digitalWrite(pinIN1, LOW); digitalWrite(pinIN2, LOW); ledcWrite(pwmChannel, 0); delay(1500); }
> ESP32 Serial Monitor Initialized (115200 baud)...

3. สเต็ปเปอร์มอเตอร์ (28BYJ-48) และไอซีขับ ULN2003

📑 28BYJ-48 Datasheet (PDF) 📑 ULN2003A Datasheet (PDF)

สเต็ปเปอร์มอเตอร์รุ่น 28BYJ-48 เป็นมอเตอร์แบบ Unipolar 4 เฟส 5 สาย ที่มีชุดเฟืองทดรอบอัตราส่วน 64:1 เหมาะสำหรับงานกำหนดมุมที่ต้องการความแม่นยำสูง โดยใช้ไอซี ULN2003 (Darlington Transistor Array) ช่วยขยายกระแสขับขดลวดแม่เหล็กไฟฟ้า

ลำดับการขับสเต็ปเปอร์มอเตอร์ (Stepping Sequences)

รูปแบบการขับ ลำดับขั้นตอน (Sequence) จำนวนสเต็ป/รอบโรเตอร์ สเต็ปหลังเกียร์ 64:1 จุดเด่น
Wave Drive (1 เฟส) A → B → C → D 4 สเต็ป 2,048 สเต็ป ประหยัดพลังงานที่สุด แต่แรงบิดต่ำ
Full-Step (2 เฟส) AB → BC → CD → DA 4 สเต็ป 2,048 สเต็ป แรงบิดสูงสุด (Torque สูง) ก้าวคงที่
Half-Step (1-2 เฟส) A → AB → B → BC → C ... 8 สเต็ป 4,096 สเต็ป ความละเอียด 2 เท่า หมุนนุ่มนวล ไม่กระตุก

#include <Stepper.h> const int stepsPerRev = 2048; // สเต็ปต่อรอบ (Full-step) // ลำดับขาเชื่อมต่อ IN1, IN3, IN2, IN4 Stepper myStepper(stepsPerRev, 8, 10, 9, 11); void setup() { myStepper.setSpeed(10); // ตั้งความเร็ว 10 RPM Serial.begin(9600); } void loop() { Serial.println("หมุนตามเข็ม 1 รอบ (360 องศา)"); myStepper.step(stepsPerRev); delay(1000); Serial.println("หมุนทวนเข็มครึ่งรอบ (180 องศา)"); myStepper.step(-stepsPerRev / 2); delay(1000); }
